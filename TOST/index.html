About

Built around the upstream OpenSteamTool flow.

TOST automates the supported install path and keeps the interface close to the Steam-style floating window workflow.

How it works
  1. 1

    Download the build

    Choose Setup if you want an installed app, or Portable if you want the app to live inside one folder.

  2. 2

    Open the floating icon

    Launch TOST and keep the icon available for drag-and-drop or menu actions.

  3. 3

    Drop supported files

    Drag the expected files into TOST and let it place them in the right destination folders.
